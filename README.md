## 📥 Installation

1. **Download** the plugin from the repository.
2. **Upload** the plugin folder to your PipraPay `Plugin` section.
3. **Activate** the plugin from PipraPay's module settings.
4. Go to **Admin Dashboard → Module → Transactions Import From Uddoktapay**.
5. Start importing your transactions from Uddoktapay.
6. **Video Tutorial:** [Youtube](https://youtu.be/A99zoN2-j8U)
